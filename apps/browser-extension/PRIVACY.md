# Privacy Policy — Masa Search Inspector

**Data controller:** Masa Media Digital LTD, https://masamedia.co.il
**Last updated:** 2026-09-23

Masa Search Inspector is a local analysis tool. It is built so that your browsing data never leaves your device.

## What the extension does

When you click the Masa Search Inspector toolbar icon, it:

1. Reads the content of the page in the active tab (its HTML, headings, meta tags, links, images and structured data).
2. Fetches that same website's `/robots.txt` file to report AI-crawler access.
3. Displays the results to you in the popup.

## What we collect

**Nothing.** The extension:

- does not send the page, its URL, or any analysis result to Masa Media Digital LTD or any third party;
- does not use cookies, local analytics, tracking pixels, or fingerprinting;
- does not create an account or collect personal data;
- does not run in the background — it only acts when you click the icon (`activeTab`).

All processing happens in your browser and is discarded when you close the popup.

## Permissions

- **`activeTab`** — lets the extension read the current tab only after you click the icon.
- **`scripting`** — lets the extension run its analysis code in that tab to read the rendered page.

No broad host permissions are requested.
